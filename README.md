# Packed Packs (UNOFFICIAL)

An unofficial Fabric backport of Packed Packs for Minecraft 1.20.1. It brings the resource and data pack profile manager from [fishstiz's original project](https://modrinth.com/mod/packed-packs) to the older game version.

## Features

- Save and switch between custom resource pack and data pack profiles.
- Select and transfer multiple packs with mouse and keyboard controls.
- Search, sort and filter pack entries.
- Organize folder packs, including nested folders, where supported by the upstream feature set.
- Keep the client-side pack management workflow available on Minecraft 1.20.1.

## Install

1. Install Fabric Loader for Minecraft 1.20.1 and Fabric API.
2. Put the release JAR in your \`mods\` folder.
3. Open Options and choose Resource Packs or Data Packs.

Packed Packs API and the compatible Fidgetz library are bundled in the release JAR. They do not need separate installation.
